# Historical density-prototype run

This is the original 216-trial density-based exploratory sweep, preserved when the experiment was converted to explicit payload-body-mass settings. In the original model, collision-disabled visual trim geometries inherited density and contributed mass. The recorded body mass in each trial reflects the compiled model, and the summary records those masses to four decimal places. This is a distinct density-prototype protocol; do not combine it with the direct-mass held-out result under `results/cooperative-pick-material-validation/` or use it as evidence for the revised mass conditions.

The archived media are illustrative replays from that earlier run and are not additional benchmark trials. The raw CSV, summary, scorecard, and demo metadata are retained as generated at the time.
