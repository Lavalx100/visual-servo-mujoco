# Intermediate explicit-inertial prototype

This is the direct-mass 216-trial run produced before the nominal model's legacy geometry-derived inertial path was restored. The explicit mass, center of mass, and principal inertia compiled to the same values as the legacy nominal model, but long contact trajectories still changed enough to alter demo and verification outcomes. The model now keeps the original geometry-derived path when the requested mass is nominal and uses explicit inertials only for off-nominal masses. This archive is preserved for traceability and is not the final material robustness result.

The CSV, summary, scorecard, and demo metadata are the original generated artifacts. The paired clips are illustrative replays from this intermediate prototype and add no benchmark trials.
